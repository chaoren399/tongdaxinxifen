这类展示的常见叫法（从通用到行业）：

1. **树形表格 / 层级表格（Tree Table / Hierarchical Table）** —— 最准确的总称
2. **合并单元格树形表（Rowspan Tree Table）** —— 你现在用的实现方式（同级单元格纵向合并）
3. **多级表头列表 / 分组表格（Grouped Table）**
4. **父子表 / Master-Detail 表格**
5. **财务/行情软件里俗称：多级栏目、纵向并栏**
6. 通达信里这种**竖排 + 合并单元格**的样式，一般叫**纵向树状行业列表**

## 建议：把它固化成本项目的标准组件

现在这套结构和样式写在 `pageH.html` 里，下次做新页面得复制粘贴。我可以抽成一个**可复用宏** `templates/_hier_table.html`，以后任何页面只要写：

```jinja
{% from '_hier_table.html' import hier_table %}
{{ hier_table(groups, columns=['一级','二级','三级','股票']) }}
```

甚至支持 2 级、3 级、4 级任意层级，股票列也可换成别的叶子内容。
